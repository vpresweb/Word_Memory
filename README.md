# Word_Memory

Веб-приложение для быстрого и долгого запоминания английских и португальских слов. Слова взяты из словарей
[Dictionary English](https://github.com/vpresweb/Dictionary_English) и
[Dicionário Português](https://github.com/vpresweb/Dicionario_Portugues): около 10 000 основных слов
каждого языка, от самых частых.

Онлайн: https://vpresweb.github.io/Word_Memory/

## Как это работает

1. **Знакомство.** Новые слова дня идут быстрым потоком: слово, перевод, произношение — 2,5 секунды на слово,
   два круга.
2. **Вспоминание.** Карточка показывает слово; вы вспоминаете перевод и только потом открываете ответ.
   Усилие вспомнить — главное, что закрепляет слово в памяти.
3. **Интервальное повторение.** Оценка ответа («Снова», «Трудно», «Хорошо», «Легко») решает, когда слово
   вернётся. Новое слово повторяется через 1 и 10 минут, затем через день; каждый удачный ответ умножает
   интервал примерно в 2,5 раза: 1 → 3 → 8 → 20 дней… Ошибка возвращает слово на переучивание.
   Это алгоритм SM-2 — тот же, что в Anki.

Слово считается **запомненным надолго**, когда следующий повтор не раньше чем через 3 недели.

## Разделы

- **Сегодня** — сколько слов повторить и сколько новых, серия дней подряд, прогноз повторений на неделю,
  кнопка «Начать занятие».
- **Поток** — быстрый показ слов с переводом и произношением (0,7–3 секунды на слово). Режим «перевод через
  полсекунды» даёт мгновение вспомнить самому. На интервалы не влияет.
- **25-й кадр** — экспериментальный режим, см. ниже.
- **Настройки** — новых слов в день, направление карточек (слово → перевод, перевод → слово, вперемешку),
  знакомство, произношение, резервная копия прогресса, сброс.

Прогресс хранится в браузере (localStorage), отдельно для каждого языка. Чтобы перенести его на другое
устройство, сохраните копию в настройках и загрузите её там.

Клавиши на карточках: пробел — показать ответ, 1–4 — оценка.

## Про «25-й кадр»

Режим показывает слово на 1/25 секунды (40 мс, можно 20–150 мс) и сразу закрывает его маской — так
быстро, что слово почти невозможно осознать. Он сделан по просьбе и честно помечен как эксперимент:

- «эффект 25-го кадра» восходит к опыту Джеймса Вайкери 1957 года (якобы вставки «Пейте кока-колу» в фильм
  увеличили продажи); в 1962 году Вайкери признал, что данные выдумал;
- исследования неосознаваемого восприятия находят в лучшем случае слабый кратковременный эффект, но не
  запоминание новых слов.

Поэтому показы в этом режиме не засчитываются в прогресс. Вспышки — не чаще раза в секунду и только в рамке
на странице; перед запуском нужно подтвердить предупреждение о мерцании.

## Структура

```
index.html               страница приложения
css/style.css            стили (светлая и тёмная тема)
js/app.js                разделы, язык, настройки, резервная копия
js/srs.js                интервальное повторение (SM-2)
js/session.js            состав занятия, статистика, прогноз, наборы слов
js/learn.js              занятие: знакомство и карточки
js/stream.js             быстрый поток
js/flash.js              режим «25-й кадр»
js/speech.js             произношение (Web Speech API)
js/storage.js            прогресс и настройки в localStorage
js/data.js               загрузка слов, подписи частей речи
data/en.json, pt.json    наборы слов
scripts/build-data.mjs   сборка наборов из словарей
tests/                   тесты (node --test)
```

## Разработка

Сборка не нужна — это статические файлы. Для запуска локально нужен любой веб-сервер
(модули и `fetch` не работают с `file://`):

```
python -m http.server 8000
```

Тесты: `npm test` (Node.js 20+).

Обновить наборы слов после изменения словарей (репозитории словарей должны лежать рядом):

```
npm run build-data
```
